# Antigravity CLI (AGY)

Official Antigravity command-line interface for the terminal, with native support for slash commands, subagents, and customizations in `~/.antigravity/` or `~/.gemini/antigravity-cli/`.

## Identifier
`agy`

## Category
CLI / Agent

## Documentation
