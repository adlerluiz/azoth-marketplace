# Codeium Windsurf Driver for Azoth

Official driver integration for **Codeium Windsurf IDE**.

## Supported Features:
- **Rules**: Synced to `.windsurfrules` and `.windsurf/rules/<name>.md`.
- **MCP Servers**: Automatic synchronization to `~/.codeium/windsurf/mcp_config.json` and `.windsurf/mcp_config.json`.
- **Skills**: Synced to `.windsurf/skills/<name>/SKILL.md`.
