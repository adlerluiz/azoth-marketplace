# Cursor IDE Driver for Azoth

Official driver integration for **Cursor IDE**.

## Supported Features:
- **Modular Rules**: Synced directly to `.cursor/rules/<name>.mdc` with YAML frontmatter.
- **Consolidated Rules**: `.cursorrules` in workspace root.
- **MCP Servers**: Automatic synchronization to `~/.cursor/mcp.json` and workspace `.cursor/mcp.json`.
- **Skills**: Synced to `.cursor/skills/<name>/SKILL.md`.
